ВВолодька FM

Личный музыкальный плеер

Володька FM — некоммерческий учебный проект: музыкальный плеер для Windows и Android, который сделал для себя один человек. Приложение не продаётся и не распространяется публично.

Зачем приложению вход в Google. Чтобы лайки и плейлисты были одинаковыми на компьютере и телефоне. Они хранятся в одном файле в папке «Володька FM» на твоём собственном Google Диске. Приложение видит только этот файл — остальной Диск ему недоступен.

Политика конфиденциальности

English

Volodka FM is a non-commercial personal study project: a music player for Windows and Android built by one person for his own use. Google sign-in is used only to keep likes and playlists in sync between devices, in a single file the app creates in the user's own Google Drive. See the Privacy Policy.
