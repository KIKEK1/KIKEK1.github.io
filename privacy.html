ВВолодька FM

Политика конфиденциальности

Последнее изменение: 27 октября 2026 года

Володька FM — личный музыкальный плеер для Windows и Android (некоммерческий учебный проект). У приложения нет своих серверов: всё хранится на твоём устройстве и, если ты включишь синхронизацию, в твоём Google Диске.

Какие данные Google использует приложение

  • Адрес почты аккаунта (openid, email) — только чтобы показать в настройках, какой аккаунт подключён.
  • Google Диск, только свои файлы (drive.file) — приложение создаёт в твоём Диске папку «Володька FM» и файл volodka-sync.json с лайками, плейлистами и подгонкой текста песен. Другие файлы Диска приложению недоступны.

Где хранятся данные

  • Ключ входа Google хранится только на твоём устройстве, в папке приложения.
  • Файл синхронизации лежит в твоём Google Диске и принадлежит тебе.
  • Данные никуда не отправляются, не продаются и не передаются третьим лицам. Приложение не показывает рекламу и не собирает статистику.

Как отключить и удалить

  • Выйти из Google в приложении: Настройки → Аккаунты → Синхронизация через Google.
  • Отозвать доступ: myaccount.google.com/permissions.
  • Удалить данные синхронизации: удали папку «Володька FM» в своём Google Диске.

Ограниченное использование

Использование и передача приложением Володька FM информации, полученной через API Google, соответствуют Правилам использования данных пользователей в сервисах Google API, включая требования об ограниченном использовании (Limited Use).

Privacy Policy (summary)

Volodka FM is a personal, non-commercial music player for Windows and Android. It has no servers of its own.

  • Google user data accessed: the account email (openid, email) to show which account is connected, and Google Drive files created by the app itself (drive.file): a folder “Володька FM” with a file volodka-sync.json containing likes, playlists and lyric timing adjustments. The app cannot see any other Drive files.
  • Storage: the Google sign-in token is stored only on the user's device. The sync file stays in the user's own Google Drive.
  • Sharing: no data is sold, shared with third parties, used for advertising or analytics.
  • Revoking and deletion: sign out in Settings → Accounts, revoke access at myaccount.google.com/permissions, and delete the “Володька FM” folder from Google Drive.
  • Volodka FM's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
